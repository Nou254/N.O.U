# N.O.U Digital Systems Central Platform

A comprehensive web-based platform for N.O.U. Digital Systems that integrates customer interaction, software distribution, and competency-based technical recruitment.

## Project Overview

This platform serves as the company's digital headquarters, providing:
- **Customer Portal**: Software downloads, technical support, project requests
- **Employment Portal**: Job applications, technical assessments, automated scoring
- **Administration Portal**: Complete management of all platform features

## Technology Stack

### Frontend
- **React.js** with TypeScript for type safety
- **Tailwind CSS** for responsive, modern UI
- **Vite** for fast development and build
- **React Router** for client-side routing
- **Redux Toolkit** for state management (optional)

### Backend
- **FastAPI** (Python) for high-performance API
- **SQLAlchemy** with async support for database operations
- **PostgreSQL** for reliable data storage
- **JWT** for secure authentication
- **Pydantic** for data validation

### Development Tools
- **Git** for version control
- **Docker** for containerization
- **Postman** for API testing
- **Figma** for UI design

## Getting Started

### Prerequisites
- Node.js 18+ and npm
- Python 3.10+
- PostgreSQL 14+
- Docker (optional)

### Installation

1. Clone the repository
2. Set up backend environment
3. Set up frontend environment
4. Configure database connection
5. Run development servers
