# N.O.U. DIGITAL SYSTEMS

## SOFTWARE AND APPLICATION CATEGORIES

**Website:** nou.com
**Document Purpose:** Definition of Software Categories for the N.O.U. Digital Platform

---

## 1. Introduction

N.O.U. Digital Systems will provide a centralized digital platform through which software, applications, websites, digital tools, and technology solutions developed by N.O.U. may be presented, distributed, licensed, or made available for download.

To make the platform organized and easy to navigate, software products will be classified according to their **primary purpose, target users, and area of application**.

A product may belong to one primary category while also carrying additional tags describing its features and supported platforms.

The following categories establish the initial classification structure for N.O.U.

The request may then go through:

Custom software may or may not be published in the N.O.U. public software catalogue depending on the project agreement and intellectual-property arrangements.

# 23. Software Platform Classification

In addition to the primary category, every N.O.U. software product should have a **platform classification**.

### Android

Applications designed for Android mobile devices.

### Web

Applications accessed through a web browser.

### PWA

Progressive Web Applications that can provide an app-like experience through supported browsers.

### Windows/Desktop

Software designed for desktop computers.

### iOS

Applications designed for Apple mobile devices where N.O.U. develops and distributes them.

### Cloud/SaaS

Software operated primarily through N.O.U.'s or a customer's cloud infrastructure.

### Multi-Platform

Applications designed to operate across multiple platforms.

---

# 24. Product Classification

Each application should also have a product status.

### Free

The user can access or download the software without payment.

### Paid

The user must pay before obtaining the applicable software or licence.

### Subscription

The user pays periodically for continued access.

### Freemium

Basic functionality is available without payment while advanced features require payment.

### Enterprise

The software is intended for organizations and may require a commercial agreement.

### Custom

The software was developed specifically for an individual customer or organization.

### Internal

The software is developed for use within N.O.U. and is not publicly distributed.

---

# 25. Recommended N.O.U. Product Classification System

Every product uploaded to `nou.com` should therefore contain information similar to:

```text
PRODUCT NAME
     │
     ├── Primary Category
     │
     ├── Secondary Categories
     │
     ├── Platform
     │
     ├── Version
     │
     ├── Product Type
     │
     ├── Free / Paid / Subscription
     │
     ├── Developer / N.O.U. Team
     │
     ├── System Requirements
     │
     ├── Description
     │
     ├── Features
     │
     ├── Licence
     │
     ├── Privacy Information
     │
     ├── Release Notes
     │
     └── Download / Access
```

This structure will allow **N.O.U. Digital Systems** to grow from simply having a download section into a proper **software distribution and product-management platform** where every application has a clear identity, category, platform, licence, version, and ownership status.
