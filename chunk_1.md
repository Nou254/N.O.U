# 1. INTRODUCTION

N.O.U. Digital Systems shall operate a structured employment assessment system through the N.O.U. employment platform.

The assessment system is designed to determine not only whether an applicant has memorized technical information, but whether the applicant can:

* Think critically;
* Solve real-world problems;
* Apply technical knowledge;
* Understand professional concepts;
* Design practical solutions;
* Troubleshoot problems;
* Make appropriate decisions;
* Work within technical and business requirements; and
* Demonstrate the competence required for the position applied for.

The assessment shall therefore combine **general reasoning, field-specific education, technical knowledge, practical exercises and professional judgement**.

---

# 2. ASSESSMENT PHILOSOPHY

N.O.U. shall not use one examination for every applicant.

A person applying for Cybersecurity should not receive the same technical examination as a UI/UX Designer, while a Project Manager should not be assessed in the same manner as a Backend Developer.

The assessment system shall therefore contain:

### A. Common Assessment

Administered to applicants across most professional fields.

### B. Category Assessment

Tests knowledge of the applicant's selected professional field.

### C. Position Assessment

Tests knowledge specific to the particular position.

### D. Practical Assessment

Requires the applicant to perform an actual task.

### E. Professional Assessment

Evaluates communication, ethics, teamwork, decision-making and professional conduct where applicable.

---

# 3. LOGIC AND CRITICAL THINKING ASSESSMENT

## 3.1 Logic Assessment Principle

The N.O.U. Logic Assessment shall **not primarily consist of mathematical puzzles, IQ-style questions or memorization**.

It shall primarily consist of **real-world problems requiring applicants to understand a situation, identify the problem, evaluate available information, consider constraints and develop an appropriate solution.**

For example:

> A company's website works correctly for employees inside the office but becomes extremely slow when accessed by customers from outside the network. The server has sufficient CPU and memory. What would you investigate first, and why?

The applicant should explain their reasoning rather than simply select an answer.

---

# 4. COMMON LOGIC MODULES

The following logic areas may be used across the N.O.U. assessment system.

### Logic Module 1: Problem Identification

Applicants are given a real-world problem and must identify the actual problem rather than the obvious symptom.

### Logic Module 2: Critical Decision-Making

Applicants evaluate several possible decisions and explain which one is most appropriate.

### Logic Module 3: Resource Constraints

Problems include limitations such as:

* Time;
* Budget;
* Personnel;
* Hardware;
* Internet connectivity;
* Security;
* Infrastructure.

Applicants must develop practical solutions within the constraints.

### Logic Module 4: Troubleshooting

Applicants receive a system failure or operational problem and must determine how they would investigate it.

### Logic Module 5: Cause-and-Effect Reasoning

Applicants determine how one event affects another.

### Logic Module 6: Prioritization

Applicants receive multiple problems and must determine which should be handled first and why.

### Logic Module 7: Risk Analysis

Applicants identify potential risks associated with a proposed solution.

### Logic Module 8: Real-World Solution Design

Applicants are presented with a practical scenario and must propose a complete solution.

---

# 5. ASSESSMENT SCORING

N.O.U. may use a 100-point assessment model.

| Assessment Area                         | Suggested Weight |
| --------------------------------------- | ---------------: |
| Logic & Critical Thinking               |              15% |
| General Computer/Professional Knowledge |               5% |
| Category Knowledge                      |              25% |
| Position Knowledge                      |              25% |
| Practical Assessment                    |              25% |
| Professional Judgement                  |               5% |
| **Total**                               |         **100%** |

The weighting should be configurable because different professions require different assessment structures.

For example, a Graphic Designer may receive a much larger practical-design component than an Accountant.
